# BF IDE

***An online IDE for Brainf\*ck, with syntax highlighting, a visualized debugger, and a fully customizable theme.***

**Try it now — [GitHub Pages](https://jayden-lxh.github.io/BF-IDE)**

---

## Features

- 🔍 **Built-in debugger** — Run, Step, Step Back, and a visualized tape.
- 🎨 **Syntax highlighting** — Every token color is fully customizable.
- 🖥️ **Terminal I/O** — Full support for the `,` command.
- ≡ **Compact menu bar** — Reveals many options without clutter.
- 🛑 **Breakpoint system** — Two modes: Click Mode and Pre-breakpoint Tool Mode.
- ⚙️ **Settings panel** — Font, Font Size, Optimal Running, and more.
- 🧠 **Theme persistence** — Remembers your customized theme.
- 💡 **Ready-to-Run Demos** — A simple "Hello, World!" and a longer echo program.
- 📄 **File loading** — Load `.bf` or `.txt` files smoothly.
- 🌙 **Dark / Light theme** — One-click toggle.
- ⏳ **Animated background** — A scrolling typewriter-style effect.
- 📱 **Mobile friendly** — Use BF IDE anywhere.
- ⌨️ **Keyboard shortcuts** — Every action has a keyboard shortcut.

---

## Quick Start

1. Type in some Brainf\*ck code, or press **Ctrl+Alt+H** to load "Hello, World!".
2. Press **Run** (`F5`) or **Step** (`F10`) to start executing.
3. Monitor the tape status as the program runs.
4. When the program hits a `,` command, type a single character into the glowing input box.
5. Press **Reset** to reset the debugger state, or **Done** to exit debugging mode.
